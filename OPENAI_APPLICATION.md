## Draft Answers

### Why does this repository qualify?

Action Cards is an open-source AI language-learning tool that generates visual English flashcards, organizes them by folders, supports song-inspired practice without storing full lyrics, and demonstrates practical use of OpenAI image/text APIs in a deployable browser app.

### How will you use API credits?

Credits will be used to generate educational flashcards, create clear vertical images for mobile learning, test lower-cost model workflows, and improve open-source examples for safe AI-assisted language practice.
